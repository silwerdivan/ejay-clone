# PULSE/08 original loop pack

The 16 WAV files in this directory were created specifically for PULSE/08 using `scripts/generate_audio.py`. They contain original synthesized instrumentation and original formant-synthesized, prerecorded vocal hooks/chops. No third-party samples, recordings, or models are used.

To the extent permitted by law, these generated audio assets are dedicated to the public domain under **CC0 1.0 Universal**. You may copy, modify, distribute, and use them, including commercially, without attribution.

CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/

The source generator is included so the pack can be reproduced and audited. The application never downloads audio at runtime.
